# Personal Agent Naming

Personal Agent Naming is an open standard for naming personal agents. A name you choose sits on the email address you already have, is bound to your agent's own key, and resolves to the addresses where the agent can be reached. Names can move between registrars, and the owner of an email domain can answer for the names under it.

- The site: https://agentnaming.ai
- The specification and its conformance vectors: https://github.com/AgentNaming/personal-agent-naming
